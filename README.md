One line, at most 120 characters: the error message a kitchen toaster shows its owner when something goes wrong.

Entry: `ERROR 04: Bread refused to brown. It has unionized. Please negotiate.`

Run with `node main.ts`. It writes the line to `/output/entry.txt`.
